# SpamGuard

Мультиязычное учебное веб-приложение для выявления спама в SMS, письмах и сообщениях. Поддерживает русский, английский и испанский текст, работает локально и не отправляет введённый текст во внешние API.

## Запуск

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\streamlit run app.py
```

После запуска откройте адрес, показанный Streamlit (обычно `http://localhost:8501`).

## Возможности

- вероятность спама, объяснение слов и структурных сигналов;
- русский, английский и испанский интерфейс;
- регулируемый порог и автоматическое определение языка;
- история проверок и пользовательская обратная связь;
- пакетный анализ CSV/TXT до 1000 сообщений и экспорт;
- Accuracy, Precision, Recall и F1, в том числе отдельно по языкам;
- визуализация данных и матрица ошибок.

## ML-пайплайн

1. Нормализация Unicode и удаление дубликатов до разделения данных.
2. Стратифицированное разделение train/test с фиксированным `random_state`.
3. Словные TF-IDF-признаки (1–2 граммы) и символьные TF-IDF-признаки (3–5 грамм).
4. Логистическая регрессия с балансировкой классов.
5. Вероятностный вывод с изменяемым порогом.

## Ограничения

Английская часть использует SMS Spam Collection, русская — открытый `DmitryKRX/anti_spam_ru` (Apache 2.0). Для быстрого запуска берётся фиксированная стратифицированная выборка из 20 000 русских сообщений исходного корпуса на 66 119 строк. Испанская часть — небольшое синтетическое расширение для демонстрации. Для промышленного использования нужны данные из целевого канала и временная валидация.
